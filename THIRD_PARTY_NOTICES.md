LICENSE. The components below retain their original licenses and notices.

The entries below cover the enabled normal and build dependency closure in
`compiler-rs/Cargo.lock` for macOS and Linux on x86-64 and ARM64, with default
features (QBE). For dual-licensed crates that offer MIT, this distribution uses
the MIT option. Build-only `cfg_aliases` is included for completeness.
Optional Cranelift and Windows-only dependencies are not part of this Unix
bundle. Each license below is reproduced from the matching Cargo registry

SQLite, or PCRE2. Those libraries are supplied separately by the host/toolchain
when linking and running native programs; their own distribution notices remain
with those packages. The notices above do not change any upstream license.
