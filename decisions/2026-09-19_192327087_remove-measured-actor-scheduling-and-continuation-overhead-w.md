* **Status**: Adopted performance checkpoint; strict BEAM performance and broader core OTP acceptance remain open
* **Decision**: Skip redundant scheduler activity locks when an owner remains busy or a live endpoint is empty, while retaining the activity fence for every definitive quiescence decision and stopped endpoint drain. Validate migrating heaps against a transient address-range index instead of repeatedly scanning every foreign heap. Use 16 inline scratch entries for common descriptor and value traversal, spilling without changing traversal or limits. Expand eligible pure actor self-tail recurrences within the existing 32-source-computation threshold, at most eight copies and 1,024 cloned syntax nodes, leaving the last call resumable and ordinary function ABIs unchanged.
* **Boundaries**: Transfer validation still refuses foreign interior pointers, active roots and exhausted work atomically. Building the foreign-allocation index consumes the work budget, so large unrelated heaps can conservatively prevent donation. Tail batching excludes effectful recurrence paths, receives, FFI, defers and arbitrary source calls; immutable owned captures remain rooted across resumptions. Neither batching nor a callback quantum interrupts a synchronous native operation. Existing logical quotas and compiler/runtime descriptor layouts remain unchanged.
* **Independent evidence**: A 64-continuation scheduler oracle reduces targeted activity acquisitions from 257 to zero. The public native continuation ABI reduces 128 small-frame validations from 128 scratch allocations to zero, with exact callbacks and payloads. A 256-foreign-heap transfer with 5,000 scalar words succeeds within the unchanged work budget; exact interior boundaries and budget exhaustion retain ownership. Two rooted 1,024-iteration recurrences now complete within 900 single-turn polls while a sibling progresses within ten; labeled argument order, swapping, cleanup, ordinary calls and effectful fallback have independent native outputs. Review found and fixed an empty-drain shutdown race: a stopped consumer must fence a producer already admitted under the activity lock. A barrier test proves the admitted spawn is rejected and released exactly once; a separate live-empty test preserves a later full-width delivery.
* **Acceptance**: macOS ARM64 `cargo xtask check` passes 2,380 Rust tests across 292 result suites, 317 native-output fixtures, 20 examples, 63 dynamic programs, 295 atomic rejections and 64+192+231 fuzz cases. ThreadSanitizer passes 189 tests with no race reports in 18.60 s; the same two long lifetime-churn tests pass in the ordinary 191-test runtime suite. Seed `0x0046524e`, 5,000 steps, retains trace `0xd4e402a412f11e2f`, 48,739 callbacks and zero cleanup residue. New benchmark evidence is archived independently from Decision161's historical report.
* **Measurements**: The [first checkpoint](../benchmarks/language-comparison/results/actors-parity-checkpoint1-20260919/PARITY.md) preserves 36 semantic smoke checks and 216 matrix observations, all passing their output oracles. Default-stealing contention throughput improves 109–117% over the earlier matrix, but none of the nine cells reaches the 0.80 competitive band or 1.00 parity target. A separate 144-process interleaved old/new diagnostic confirms a stealing-specific request/reply regression: two-scheduler ratios are 0.600 for 32×500 and 0.494 for 32×5,000; four-scheduler ratios are 1.038 and 0.868. Pinned two/four-scheduler ratios improve 1.24–1.42×. Preserve this checkpoint as evidence and correct the migration regression before accepting the optimization group as a performance improvement overall.
* **Parity scope**: The [performance acceptance plan](../docs/superpowers/specs/2026-09-19-actor-performance-parity.md) requires matching BEAM medians in all nine unchanged workload/scheduler cells, followed by confirmation and broader workload coverage. The user also selected local core OTP behavior: isolated processes, ordered monitor/link events, atomic relationship spawn, supervisor strategies, rolling restart intensity and shutdown policies. The [process-model proposal](../docs/superpowers/specs/2026-09-19-typed-otp-process-model.md) defines staged tests and explicit typed-reason, quota, legacy-fault and cooperative-native differences. This checkpoint implements none of those new process APIs and establishes no parity claim.
