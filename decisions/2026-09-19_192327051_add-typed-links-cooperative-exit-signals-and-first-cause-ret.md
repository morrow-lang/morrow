* **Status**: Adopted local link/exit stage; supervisor stages remain pending
* **Decision**: Add actor-only `Process.link`, `unlink`, atomic `spawn_link`, `trap_exit`, terminal `exit` and `signal_exit`. Preserve typed immutable process identities, copied messages, the ordinary boxed Result ABI and legacy spawn/supervision behavior. Links are symmetric and idempotent; epochs distinguish cancellation and relinking. Direct Kill forces Killed despite trapping, while linked or locally chosen Kill remains an ordinary trappable reason. Native callbacks remain cooperative.
* **Retirement and ordering**: Commit the first terminal cause before cleanup. Latch checked callback, selector and cleanup faults before later ingress, including while cleanup temporarily resets its fault cell. Preserve their checked origin so later signals cannot bypass legacy restart/root-failure policy; explicit exit with a Fault reason remains distinct. A later admitted direct Kill may skip unstarted cleanup without replacing the first cause. Release runtime roots and charges once, reject new user messages to Exiting actors, and permit pre-retirement observers to see the committed cause. Publish linked exits before Down completions across bounded batches of at most64 retirement actions, with iterative cyclic cascades and pending work included in quiescence.
* **Admission and ownership**: Reserve two directed link slots atomically. Each future monitor/link completion reserves512 control bytes plus4097 bytes for the maximum textual reason copy; direct signals reserve their actual receiver-copy cost, and shared immutable reason storage has a separate charge. Retain the256 recipient/4096 invocation slot limits and64MiB logical bound, with separate physical accounting. Text is bounded to4096 UTF-8 bytes. Oversized signals return InvalidOptions; invalid local custom exit admission becomes checked fault9; malformed native ABI remains infrastructure fault11. An admitted direct Kill needs no later fallible reason admission. Preserve activity→sorted routes→registry lock order, owner-local accounting and callback/GC publication outside registry locks.
* **Compiler semantics**: Internal Never makes explicit exit terminal through operand, statement and continuation lowering while retaining earlier Result obligations. ScopeLeave status2 routes through the rooted return path before successor continuations. Faulting operands retain their original cause and cannot commit exit. The native interface remains full-width and additive.
* **Independent regressions**: Preserve red/green evidence for pre-envelope clock-fault reservation leakage, forced cleanup before and during defers, the64-action fanout boundary, terminal ScopeLeave continuation escape, Exit-before-Down publication, timer/selector safe points, and callback/cleanup Fault5 overwritten by later Kill. Real blocked-worker/defer barriers also prove legacy restart is retained. Tests cover ring/dense cascades,4096-observer fanout, remote install/unlink churn, migration, stop-after-admission, full-width/text reasons, exact quotas, rollback and precise event GC. Trap toggling and simultaneous endpoint death have semantic/cascade coverage, not separate dedicated two-phase barrier oracles.
