# Morrow visual identity

Morrow uses a plain text mark while its new logo is being designed. The text
identity keeps repository and documentation headers accurate without carrying
forward Fern's frond artwork. Use the name “Morrow” as accessible text wherever
the project identity appears.

The previous raster logo files were removed during the rename. A future logo
should be added here with its source, variants, accessibility guidance and
generation or design provenance.
